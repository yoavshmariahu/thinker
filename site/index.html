Your software factory, faster and cheaper.

Coding agents have transformed the software development lifecycle with automations in every step to production. Thinker wires into your coding agents and finds cost-saving opportunities or efficiency improvements to make sure your agents produce accurate work without burning through your token budgets.

What thinker does

Compression

Thinker watches each session and removes older tool results the agent has finished with, only when the saving is worth the cache rewrite. Fewer tokens read on every call that follows.

Memory profile

From your prompts and your agents’ answers, thinker learns what you are working on, how you want work done, and where agents went wrong here before. Every session starts with that, so you repeat yourself less and get closer to one-shotting a change.

Find savings

See what each instruction section, skill and tool costs per prompt and how often sessions act on it. Trim, compress or switch off what they never use, as pull requests you review.

Compression: use only the context you need.

Thinker identifies cost saving opportunities to safely remove context from your coding agent session. We calculate the cost to re-write the cache compared to how much the context shrinks, and identify the savings on input tokens will be paid off after at most 25 API calls. Typical sessions span hundreds of calls, so a single context cut can significantly reduce your token spend on the session. See the data for examples on how we cut costs on real work on open-source repos.

Memory profile: start every session already knowing you.

Thinker reads a session’s prompts and the agent’s answers, never your code or tool output, and keeps a ledger of what was asked, how it went, and what you said back. Once a day it compiles that into a short profile for the repository, in three parts:

  • Working on. The workstreams you are in the middle of, so the agent picks up where the last session left off.
  • How this person works. Rules in the imperative, from your stated preferences and the corrections you had to make more than once.
  • Skills. Which skills you run here and how they went.

The profile goes into the first prompt of every session, about 1,500 tokens, and again after a compaction. It lives in the repository’s local thinker folder and is never committed or uploaded. Half of sessions are held out, and thinker measures how often you had to say something again that you had said before.

One command. Nothing to change in your workflow.

npx thinkersh connects thinker to the agents on your machine through their own settings. No API key, no code changes, no new commands to learn. Keep coding as usual; thinker works in the background and says something only when it has something worth saying.

Your sessions, your profile and your reports stay on your machine. Thinker sends anonymous usage counts, which one setting turns off, and error reports only after you say yes to each. The code is open source under the MIT license. thinker uninstall --user removes everything it wired.

Measured, not promised.

Every number on this site comes from a recorded session: the model calls, what each cost, what was removed, and whether the task passed. The runs, their transcripts and the assumptions are published, limitations included. One run per task is a data point, not a general claim.
