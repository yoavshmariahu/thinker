Every tool result stays in the prompt and is re-read by every later call.
Ten calls in, the agent is paying for 180k tokens of mostly old output.
thinker sits between the agent and the API. Past 140k, at the next turn, it replaces the old tool results with a one-line placeholder in the request it forwards. The API is asked nothing.
The newest turn and the last three results stay. Your prompts, the call text and the agent's thinking are never touched.
The placeholder says the result was read in full and can be read again. What was cut stays cut, call after call, so the prompt cache holds.
