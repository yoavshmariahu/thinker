Where thinker stepped in

    Read this before the numbers.
    • One run per arm. This is a paired measurement, not a powered sample. The sign at the one-hour write rate is within what one more run could move.
    • The workload is reading. Each turn reads two to seven source files of a Node.js repository and runs a few commands, then answers a question about them. It is what the clearing is for, and a best case by construction: nothing is edited.
    • Prices are list prices for Claude Opus 5.5 on a metered API key, per million tokens: input $4, output $20, cache read $0.20, cache write $8 at the one-hour TTL and $5 at five minutes. Claude Code writes with the one-hour TTL. A subscription pays none of this.
    • The control ran second and inherited the first run's prompt cache, so it skipped the 39k tokens of cache write that a cold session pays on its first two calls. The checkbox above charges it those; unchecking shows the control exactly as billed.
    • What a cost cannot see. In four turns the thinker run's answer flagged line counts it had already given as unverified, because the raw file was gone from its context. The figures it flagged matched the control's. The control's answers never said so. Nine of fourteen answers were identical in both runs, five differed by one line in both directions, none left a value out.
    • Tokens are what the API reported on each call. The track view apportions each run's measured prompt by the character counts of the results in thinker's own request bodies, so it is an illustration of the same measured total.
