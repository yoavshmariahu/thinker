What each call carried

Tokens in the prompt of every model call: the system prompt, the conversation so far and the tool results in it. Without thinker it only grows. Each dashed line is a cut, where thinker replaced the results the model had already used with a one-line placeholder; a hollow tick is a cut it priced and refused.

What it cost, call by call

Cumulative cost at list prices: fresh input, prompt-cache reads, cache writes and output, each at its own rate. A cut saves reads on every later call and pays a cache write once, so the green line dips below the blue only after the write has been repaid.

Where the dollars go

The same totals split by what the API charged for: prompt-cache reads (the conversation re-read on every call), cache writes (new material, and the rewrite a cut provokes), output, and the little fresh input. thinker trades reads for writes; whether that pays depends on the write price, which is why the TTL toggle matters.

The two context windows at this call

Each run's prompt at the selected call, apportioned by the size of the results in its own transcript. Solid blocks are results the model can read; hollow ones are placeholders thinker left behind. Drag the scrubber above, or press play.
