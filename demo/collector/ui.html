A session is an upsert keyed on install and session id, never an addition: its clearing figure settles a few turns after the cut, so the same session arrives again carrying more. Every rate is a ratio of sums. Dollars are the ones each machine priced at list rates; a session whose model has no price is counted as a session and in no dollar figure. Net is cleared at the cache-read rate, less the cache writes after a clear, less the re-reads of cleared files.
