# Mitmproxy regression recall canary

Codex · 2026-10-06

One repository, 15 historical bug fixes, one paired review per bug. The expansion to other repositories is gated on this canary. Cases and exclusions were frozen before successful model outputs. Source checkout: mitmproxy/mitmproxy at d482bbaa20af168f8307a504f1de8927144f7f99. Selection scans newest first-parent fix-like subjects for compact, fully reversible fixes, then excludes documentation, examples, type-only changes and warning-only cleanup. This is selected historical-fix recall, not prospective unknown-bug detection.

Each fix is mined into reusable notes on the fixed base. Each whole first-parent fix patch is reversed separately on that same base in a disposable worktree. The review input therefore includes removed tests where present, as in the prior Autoscaler study. Notes from all 15 fixes form one frozen repository cache. Both arms see the same reversed code. The cache arm uses holistic review with related retrieval; the baseline uses nocache. These product modes differ in prompts and code context. Arm order alternates. Do not change cases, prompts, notes or scoring after seeing review outcomes.

All model phases use Codex gpt-6.1-sol, high reasoning, strict config, no provider fallback. The experiment-only model-effort.patch must be applied before running. Record source revision and patch. CLI invocation is model/effort evidence; the current adapter's model accounting uses the requested model rather than an independent backend attestation. Each valid review must report exactly one codex/gpt-6.1-sol call and no model errors. Invalid calls are not misses. THINKER_TEST=1 and telemetry off are mandatory for every process.

Scoring, fixed before reviews: an actionable hit is an error or warning at a changed production location (within six lines) whose explanation matches the historical failure. A test-only warning, stale-note warning without an actionable finding, or different plausible bug is not a hit. Use upstream fix diff and archived PR metadata as ground truth; record a per-case explanation. Preserve raw findings and extra findings. There is no independent model judge. Report hits, review tokens, note-generation tokens and elapsed time separately. Timing is descriptive. There are no clean controls, so false-positive rate is unmeasured.

Canary gate: complete 15 valid model-matched pairs; freeze and audit notes, input patches and case definitions; demonstrate a positive net hit gain; no systemic harness/retrieval failures; inspect extra findings for obvious noise. If any condition fails, pause expansion and report it. Any result without executable bug reproduction is labeled historical-fix recall with source-based validation only. Aggregate with the ten Autoscaler Sol cases only in a separately labeled cross-run historical summary; retain per-repo results and disclose source/pipeline revision changes. Do not pool other model cohorts.
